# IRセンサーの値 → 壁までの距離の換算

ブランチ `feature/wall-distance`。スラロームの停止位置を壁センサーで自動で測る（`tools/SLALOM.md` の「次の作業」4）ための準備。

## 前のセンサーの校正（Device → IR → Front sweep）

1. メニューで決定してから3秒（LEDバーが消えていく間）に，機体の後端を区画の後壁に当てて置く（スラロームの試験と同じ置き方）。
   前の壁が近いと前のセンサーがふさがれてメニューの決定ができないので，壁から離して決定する。前の壁を
   - `Front sweep 1 cell` … 1区画先の境界に置く（車軸から壁の面まで 126mm）
   - `Front sweep 2 cells` … 2区画先の境界に置く（306mm。間の区画には壁を置かない）
2. 機体は前の壁へ 40mm/s で近づき（車軸から壁まで `FRONT_TO_AXLE_MM + 5` = 65mm，前端と壁のすき間 約5mm），
   1秒止まって，同じ速さで元の位置へ戻る。ログは `tools/log/ir_sweep/front_<n>cell.csv`（既定で連番で残る）
3. `python3 tools/fit_ir.py` を実行する（`tools/log/ir_sweep/front_*.csv` をすべて使う）。結果は `tools/ir_calibration.json`

正解の距離はエンコーダから作る：車軸から前の壁の面まで `180·n − 12 − BACK_TO_AXLE_MM − 進んだ距離`。
`BACK_TO_AXLE_MM`（42）と `FRONT_TO_AXLE_MM`（60，概算）は `Core/Inc/config/mouse_config.hpp`。

### fit_ir.py がすること
- 4つの変数（`ir_var_L/FL/FR/R`）を，壁から離れるほど値が一貫して下がるもの（前のセンサー）と，そうでないもの
  （横のセンサー）に分ける。横のセンサーは，前の壁の影響が出始める距離と84mm（区画中央で止まったとき）での値を出す
- 前のセンサー：値が最大になる距離（ピーク）を探し，それより遠い側の1mmごとの中央値に「距離に対して単調に減る」
  制約をかけて換算表（値 → 距離，2mmごと）を作る。分解能（1サンプルのノイズ ÷ 傾き）が3mmより悪い所は外す
- 精度は，近づくときのデータで作った表を離れるときのデータで確かめる（逆も）。ログが2本以上あれば，1本を除いた
  残りで作った表で除いた1本を換算する（走行をまたいだ精度）。走行ごとの値の倍率と，倍率を直したあとの偏りも出す。
  分解能は走行ごとのノイズで求める（走行をまたいだ違いを混ぜない）。比較のためモデル
  `d = A·v^p`，`d = a/√(v − b) + c` の残差も出す（`--table` で10mmごとの値も）

### 実機でわかったこと（2026-10-02，Front sweep 2 cells，電池7.9〜8.4V）
- **前のセンサーは変数 `irFL`・`irFR`**，`irL`・`irR` は横のセンサー。`feature/search` の `wall_sensor.cpp` `pick()` の
  対応（irR = 前左，irL = 前右）とは合わないので，探索を実機で試す前に直す（左右は手でふさいで確かめる）
- ピーク：irFL 66.5mm（64〜76mmは受光が飽和に近く値がほぼ平ら），irFR 75.5mm
- 換算表の精度（近づく⇔離れる）：80〜170mm で 0.2〜0.6mm，170〜230mm で 0.6〜1.2mm，230mm〜で約2.4mm。
  モデル（power / inv_sqrt）は近い側の形（飽和）を表せず 2〜12mm なので，**換算は表を使う**
- 横のセンサーは前の壁が約90mmより近いと値が上がる（84mm で irL +31%，irR +21%）。少し前を向いているため。
  区画中央で止まって横の壁までの距離を測るときはこの影響が入るので，横のセンサーは前の壁がある状態で校正する

### 走行をまたいだ精度（2026-10-02，1 cell 1本 + 2 cells 3本）
- 1回の走行の中では 0.3〜0.6mm だが，**走行をまたぐと数mm〜17mm ずれる**。違いの大部分は走行ごとの値の倍率
  （irFL 0.94〜1.04，irFR 0.87〜1.09）で，倍率を直すと 130mm より遠い側は ±1〜2mm に収まる
- 最初の 2 cells（21:02）だけは倍率を直しても近い側が合わない（80〜100mm で irFL −6mm，irFR −12mm）。形も違う
- 電池の電圧では説明できない（最初の 2 cells は電圧が一番高いのに値が一番低い）。候補は機体の向き・横の位置・
  前の壁（板の違い・傾き・置き直し）。1 cell と 2 cells は前の壁が別の壁

## 次の作業
1. 走行ごとの倍率の原因を切り分ける：
   - 迷路をまったく変えずに置き直すだけで3回（置き方のばらつきだけ）
   - わざと横に ±5mm，向きを ±2° ずらして置く（どれだけ倍率が変わるか）
   - 前の壁の板を替える・置き直す（壁による違い）
   倍率が壁や置き方で変わるなら，測る前にその場で倍率を合わせる手順（既知の距離で1回測る）を入れる。
   向きで前左・前右が逆に変わるなら，2つの差から向きを求めて直す
2. 横のセンサーの校正：横には走れないので，区画の中でその場旋回し，ジャイロの角度と幾何から壁までの距離を出す試験を作る
3. `ir_calibration.json` から換算のヘッダを生成する（スラロームと同じく JSON → 生成スクリプト → ヘッダ）。
   有効範囲の外（ピークより近い・遠すぎる）は無効として扱う
4. スラロームの試験で，止まった後の壁までの距離から外側・前後・向きを測り，`identify_slip.py` が読むようにする
   （`feature/slalom` と，センサーの対応を確かめた `feature/search` を合わせてから）
