# 角速度の目標追従性能レポート（現行ファーム，並進700mm/s）と 2000mm/s・大角速度への外挿可否

作成の元データ：E9〜E11（`tools/log/omega_ff_v700_x/`），集計スクリプト `omega_tracking_report.m`，
出力 `results/omega_tracking_summary.csv`（レベル×構成の平均±標準偏差），`results/omega_tracking_by_run.csv`（run単位），
`results/omega_tracking_overview.png`（レベル別の指令と実測）。詳細な経緯は `rot_gain_scheduling_plan.md`（§1〜§22）。

## 0. 結論（先に）

1. **追従性能**：現行制御（PI＋2自由度FF）は，並進700mm/s・最大角加速度2500dps/s²のランプ指令に対し，
   - **定常値は全レベル（±100〜±430dps）で目標の±2%以内**。
   - **立上り**は FF なしの純PIに比べ，±430で **90%到達が約56〜59ms 短縮（199→142ms，192→130ms）**，
     **ランプ追従の RMS 誤差は約90dps→24〜42dps**。旋回角の指令からのずれ（0.6s）は **±11〜17°→約±1〜2°（旋回量の約1%）**。
   - **OS は 3〜10%**（動作点と電池・感度の状態で変わる）。±430は3.7〜4.8%，±250/±100は E9で3〜4%，E11で3〜9%。
   - **47Hzのジャイロリップル**（+430で標準偏差≈37dps＝約9%）は残る。プラント由来で制御では消えない（§11.4）。
2. **2000mm/s・大角速度の特性は「部分的にしか予測できない」**。
   - **予測できる**：運動学（左右輪速・輪の逆転条件・横加速度・必要な駆動余裕）と，「今の `DUTY_DIFF_LIMIT=0.28` では足りない」こと。
   - **予測できない（実測が要る）**：プラントゲインK・時定数T・静的写像・FF表の値・吸引ONの影響。
     現在のデータは**並進700mm/s・最大ω≈430（開ループ試験で974）dpsの範囲しかない**ため，K, T, FF表の値の外挿は根拠が弱い。
   - 上限0.28は，2000mm/sでは仮説次第で **ω≈80〜215dps で頭打ち**（430dpsには0.37〜0.59が必要）。**上限の引き上げ（電圧基準）が前提**。
   - 推奨：並進速度を 700→1000→1400→2000mm/s と段階的に上げる同定試験（§6）。

## 1. 対象と指標

- 制御：gyro_z の PI（Kc=5e-4，Ti は |ω_ref| のテーブル）＋静的FF（表）＋加速度FF（表）。指令は 2500dps/s のレートリミット（`omega_ref`）。
  並進は700mm/s固定。バッテリ 7.6〜8.3V。
- 現行ファームは F7（+側の加速度FFが F5 の1.6倍）。E11 で F7 は F5 より良くない（OS +1.5pt）と判明済みだが，
  差は追従性能の全体像に比べて小さいので，ここでは **F7 の FF ON 実測を「現行」**とし，±250/±100 には F5（E9）を参考に併記する。
- 指標：定常誤差（0.4s以降のgyro平均−目標），ばらつき（生のσ／100ms移動平均のσ），OS（100ms移動平均の最大値），
  90%到達（20ms移動平均），10%整定（±10%帯へ最後に入る時刻），ランプ追従誤差（ランプ区間の gyro(20ms平均)−ω_ref の RMS／最大），
  角度誤差（励振開始〜0.6sの ∫(gyro−ω_ref)dt）。
- 除外：E11のウォームアップ1本（`omega_f7_ff_pos430`），係数を変えた比較用（ffold/ffhi），E9/E10の noff（感度状態が異なるため）。

## 3. 読み取り

### 3.1 追従できているところ

- **定常値**：全レベルで平均誤差が ±2%（±250で最大 +3.6%は n=1）。積分器が効き，感度の違いは定常誤差にはほぼ出ない。
- **FF の効果（E9・E10・E11 の3セッションで再現，隣接ペア差）**：
  - +430：90%到達 **−59.2 ± 4.9ms**，指令への遅れ −8.8pt，OS −4.6pt。
  - −430：90%到達 **−55.8 ± 1.4ms**，指令への遅れ −14.7pt，OS 差なし，飽和 +6.5pt。
  - ランプ区間の追従誤差：RMS 約88〜91dps → 24〜42dps（±430）。純PIは目標に届くまで約100〜200ms遅れて走るのに対し，
    FFありは指令のランプにほぼ沿う。
- **小さい角速度**（±100）：立上り33〜46ms，ランプ RMS 4〜16dps，σ 100ms 0.4〜1.4dps。実用上十分な追従。

### 3.2 追従が弱いところ

| 項目 | 内容 | 原因（分かっている範囲） |
|---|---|---|
| +430 の谷（10%整定 348ms） | OS の後に −10%近くまで沈み，+430のみ元に戻るのが遅い（図左上） | +側のプラントの局所時定数が長い（約290ms，−側は約75ms）。FF は立上りには効くが，この遅い成分には効かない |
| ±250 / ±100 の OS（E11で8〜11%） | E9では3〜4% | 電池が高く感度が高い状態で，保守側の固定静的FFが過大（§22.3） |
| −430 の飽和 | FF あり 6.5% / なし 0.2% | FF合計（静的0.22＋加速度0.09≒0.31）が上限0.28を超える。性能への影響は小（90%到達142ms，OS 3.7%） |
| 47Hz リップル | +430 σ 約37dps（生），100ms平均で13.5dps | プラント由来。制御で低減できないことは確認済み |
| 感度ドリフト | 同じ指令で必要duty（u_ss）が電池・時間で最大約20%動く | 電池電圧（−側で分散の約7割）＋他要因。F6（電圧補償）／F8（自動較正）で対処予定 |

### 3.3 注意（この表の信頼度）

- ±250 と ±100 の F7 は n=1〜2 で，run 間ばらつきは見積もれていない（±430 の n=8〜11 を根拠の中心にすること）。
- 全て**並進700mm/s固定・壁なし**の空間での旋回。減速中・スラローム・他の並進速度での性能は未検証。
- ジャイロ/エンコーダ比が0.88（実効トレッド約68mm），IMUドリフトの影響は小さい（静止オフセット≦0.2dps，走行中≦約9dps）。

## 4. 「現在の特性」から分かっていること（外挿の前提）

いずれも並進700mm/sでの実測。

| 項目 | 値 |
|---|---|
| 回転プラント | 動作点ごとに1次遅れ近似：T 10〜160ms，K 550〜3200dps/duty（K/T≈4000〜6000dps/s）。**非線形** |
| 静的写像（duty_diff→ω） | |diff|≦0.06 の線形域で約727〜767dps/duty。それ以上では遅い側の輪のduty（base−diff/2）が0付近の不感帯・低duty域に入り傾きが下がる（430dpsに約0.19〜0.20，−側は約0.03増） |
| 上限 | `DUTY_DIFF_LIMIT`=0.28（430dps到達に必要な約0.19〜0.22＋余裕） |
| 並進 | K_p=1518.9mm/s/V，T_p1=0.445s，不感帯U0=0.136V，700mm/sの基本duty≈0.071（同定は約900mm/sまで） |
| 機体 | 輪半径11.8mm，ギヤ13/42，エンコーダ4096，トレッド60mm（実効約68mm），IMU ±2000dps，MAX_DUTY=0.95 |

## 5. 2000mm/s，より大きい角速度の特性は予測できるか

質問：吸引でタイヤがスリップしないと仮定し，並進約2000mm/sでより大きい角速度に追従させたときの特性を，現在の特性から予測できるか。

**答え：構造と運動学は予測できるが，制御性能を決める K・T・静的写像・FF表は予測できない（700mm/sのデータだけでは根拠が足りない）。**
以下，(a)予測できる量，(b)仮説で範囲を絞れる量，(c)予測できない量に分ける。

### 5.1 (a) 予測できる量（運動学・駆動余裕）

輪速 v_R,L = v ± ω·T/2（T＝トレッド。60mmと実効68mmで幅をとる）。

| 並進v | ω | 速い輪 / 遅い輪 [mm/s]（T=60） | 遅い輪が停止するω（T=60 / 68） | 横加速度 v·ω |
|---|---|---|---|---|
| 700 | 430 dps | 925 / 475 | 約1340 / 1180 dps | 5.3 m/s² ≈ **0.54 g** |
| 2000 | 430 dps | 2225 / 1775 | 約3820 / 3370 dps | 15.0 m/s² ≈ **1.5 g** |
| 2000 | 1000 dps | 2523 / 1477 | 同上 | 34.9 m/s² ≈ **3.6 g** |

- 輪速そのものは700mm/sでも430dpsで逆転しない（遅い輪475mm/s）。しかし**遅い輪のduty（基本duty − diff/2）**は，
  700mm/sでは 0.071−0.10 ≈ −0.03 と0付近〜負になり，不感帯・低duty域の非線形に入る（実測の非線形の主因）。
  **2000mm/sでは基本dutyが約0.16なので，同じ430dps（diff≈0.2〜0.4）でも遅い輪のdutyが0以上に保たれ，この非線形域を通らない**
  可能性が高い。プラントは700mm/sの旋回より**線形に近い**と予想される（§5.2）。
- 横加速度は 430dpsで約1.5g，1000dpsで約3.6g。タイヤの限界グリップに直結するので，**吸引の下向き力が必須**
  （「スリップしない」を仮定するなら，その分の吸引力が要る）。
- IMU ±2000dps には余裕がある。ただし 2000dps 級の指令は入らない前提。
- 基本duty：並進モデルの外挿で約0.16〜0.18（700mm/sで0.071）。速い輪のduty ≒ 基本duty + diff/2 ≦ 0.95 から，
  duty余裕は約 diff ≦ 1.5。**電源側の余裕は大きい**（ただし外挿）。
- エンコーダは約356counts/ms（2000mm/s）：カウンタ・処理周期の余裕は別途確認（本レポートでは未確認）。

### 5.2 (b) 仮説で範囲を絞れる量：必要な duty_diff と現行上限

線形な差動モードモデル（左右輪が独立に v = K_p·(u−U0)）が成り立つなら，回転の動特性は基本速度に依存しない。
実測で非線形が出るのは遅い輪の duty（base − diff/2）が0付近に来たとき（700mm/s：diff≈0.14）なので，
2000mm/sでは線形域が diff≈0.33 まで広がるはず。ここから，必要な duty_diff について2つの仮説で範囲を絞る：

| 仮説 | 内容 | 430dpsに必要な diff | 0.28で頭打ちになるω |
|---|---|---|---|
| **H_lin**（線形域の傾きが基本速度に依存しない） | ω ≈ 727〜767dps/duty × diff | **約0.56〜0.59** | 約200〜215dps |
| **H_x**（ωは遅い輪のduty＝base−diff/2 の関数。700mm/sの写像を平行移動） | 700mm/sで430dpsのときの遅い輪 ≒−0.03 → 2000mm/sの基本duty0.16では diff=2(0.16+0.03) | **約0.37〜0.41** | 約80dps |

- どちらの仮説でも **`DUTY_DIFF_LIMIT`=0.28 は不足**（430dpsにも届かない）。真の値は両仮説の間か，別の機構になる可能性がある。
- 実際の必要 diff は，「遅い輪の低duty域が線形に近づくか」で決まる。**線形なほど必要 diff は大きくなる**（H_lin の方が大きい）。
  つまり，線形域が広がるのは制御には好都合だが，**上限（電圧基準の表現）の設計は大きく変わる**。
- 実務上の含意：`DUTY_DIFF_LIMIT` の再設計（F6a：電圧基準）が必要。速い輪が MAX_DUTY(0.95) に当たるまでの余裕は
  2(0.95−0.16)≈1.6 なので，上限を0.5〜0.6にしても電源側には余裕がある（ただし並進dutyの外挿値に基づく）。

### 5.3 (c) 予測できない量（要実測）

| 項目 | 予測できない理由 |
|---|---|
| **プラントゲインK・時定数T** | 動作点ごとに T 10→160ms，K 550→3200 と大きく変わる（非線形）。700mm/s周辺でしか測っていない。速度が違えば逆起電力の割合・遅い輪の動作点が変わる |
| **静的FF表・加速度FF表** | 表の値は700mm/sの静的写像・局所応答から作ったもの。H_lin（傾き一定）ならほぼ直線（430dpsで約0.56）になり，現行表（430dpsで0.178〜0.22）と全く違う |
| **PI の Ti テーブル・Kc** | Ti はプラントの動作点別時定数から決めたもの。K が変われば PI のループゲイン（Kc×K）が変わる（K が2倍なら安定余裕・OSが変わる） |
| **吸引の影響** | 吸引は輪の垂直荷重を増やす → 転がり抵抗・旋回のスクラブ（横滑り抵抗）が増える → 旋回に必要な差動トルクが増え，ゲインKは下がる。**吸引なしのデータ（スリップ・スクラブを含む，ジャイロ/エンコーダ比0.88）は，吸引ON・スリップなしの状態を代表しない** |
| **47Hzリップルの周波数・振幅** | 発生源が特定できていない。輪・ギヤ由来なら速度に比例して周波数と振幅が変わり，制御帯域に近づく可能性 |
| **並進ループとの干渉・電池電圧** | 並進の同定は約900mm/sまで。2000mm/sでは電池電圧で速度・トルク余力が決まり，旋回の飽和（片輪が0.95に張り付く）が並進を乱す |
| **大きい角速度での指令追従** | 2500dps/s のレート制限だと 1000dpsに0.4s。これは指令制限であり，プラントの限界は別に見る必要がある |

### 5.4 予測の確度まとめ

| 量 | 確度 | 備考 |
|---|---|---|
| 輪速・横加速度・輪の逆転条件 | ◎（幾何学） | トレッドの不確かさ（60〜68mm）は±10%程度 |
| 「上限0.28では不足」 | ○ | 2仮説とも同じ結論。必要量は0.37〜0.59の幅 |
| 線形域の拡大（遅い輪のdutyが0以上に保たれる） | ○ | 2000mm/sでは diff≈0.33 程度まで低duty域に入らない見込み（並進dutyの外挿に依存） |
| ゲインK・時定数T | △〜× | 同定が必要 |
| FF表・PIゲインの最適値 | × | 再同定・再調整が必要 |
| 吸引ONの効果 | × | 実測が必要（増える負荷の大きさが未知） |
| 追従精度（OS・立上り・誤差） | × | 上の量が決まらないと言えない。**現行700mm/sの数値（§2）を2000mm/sの予測値として使うことは推奨しない** |

## 6. 予測を実測に置き換えるための実験案（2000mm/s・吸引ON）

700mm/sで行った手順（§1〜§22）を，並進速度を上げながら再利用する。

1. **事前**（1回だけ）：
   - `DUTY_DIFF_LIMIT` を上げる（F6a：電圧基準＋基本duty余裕で頭打ち，暫定で 0.28→0.5〜0.6 の試験専用値）。バッテリ電圧補償（F6b）を併用すると，
     電池差による感度ドリフトを切り分けやすい。
   - 試験は低電圧ガード（8.0V未満で中止）を継続。
2. **段階的な速度スイープ**：並進 **700 → 1000 → 1400 → 2000mm/s**，各速度で ±100/±250/±430dps の開ループステップ（duty_diff を階段状に与える）
   を行い，ω_ss と duty_diff の関係，および1次遅れ近似の K, T を取る。
   - 判定：**ω_ss vs 遅い輪のduty が速度によらず重なるか（H_x）**，**ω_ss vs diff が速度によらず同じ傾きか（H_lin）**。
     これで §5.2 の2仮説のどちらか（または両方外れ）が決まり，必要な上限・静的FF表が直ちに出る。
   - 各速度で吸引 ON／OFF（可能なら吸引OFFで並進を上げても危険でない速度まで）を比較し，吸引の影響（Kの低下・スクラブ）を分離する。
3. **閉ループ確認**：静的FF表・Ti表を実測から更新し，ランプ指令（±250/±430/それ以上）で 追従指標（本レポートの §1 の指標）を取り直す。
   ジャイロ/エンコーダ比（0.88）が吸引ONで変わるか（スリップなしになったか）は，その場旋回の角度検証で確認する。
4. 追加：旋回中の並進速度の維持（並進ループのσ）と，速い輪のduty最大値（0.95に張り付かないか）を全runで記録する。
